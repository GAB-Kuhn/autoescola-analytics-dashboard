# Autoescola Analytics Dashboard

Solução completa de Business Intelligence & Data Analytics para gestão estratégica de uma autoescola, integrando pipeline de dados (ETL em Python + MySQL) a dashboards interativos no Power BI.

## Dashboards:
 - **Visão de Alunos (Captação)**:
Análise mensal de matrículas, distribuição por faixa etária (Jovem, Adulto, Idoso) e efetividade dos canais de aquisição de clientes.

 - **Visão de Desempenho (Aprovação)**:
Taxa de sucesso na 1ª tentativa dos exames práticos (Categorias A e B) e ranking de veículos por índice de aprovação.

- **Visão de Frota (Custos)**:
Monitoramento de custos operacionais por veículo e modelo.

## Arquitetura e Tecnologia:
 - Fonte de Dados: MySQL & Excel
 - ETL & Integração: Python
 - Data Prep & Modelagem: Power Query 
 - Visualização: Power BI
